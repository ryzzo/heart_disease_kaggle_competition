# Heart Disease Kaggle Competition
Machine learning project focused on predicting heart disease risk using clinical and patient health data from a Kaggle competition dataset. The project explores data preprocessing, feature engineering, model training, evaluation, and comparative analysis using supervised learning techniques in Python.

## Project Overview
This project was developed as part of independent machine learning practice using Kaggle datasets and workflows. The objective was to build and evaluate predictive models capable of identifying the likelihood of heart disease based on patient medical indicators and health metrics.

The project provided practical experience with:

* real-world tabular healthcare datasets
* data cleaning and preprocessing
* exploratory data analysis
* feature engineering
* classification algorithms
* model evaluation and optimisation

The repository demonstrates practical understanding of end-to-end machine learning workflows and predictive analytics using Python-based ML libraries.

## Features
* Data preprocessing and cleaning
* Exploratory data analysis (EDA)
* Feature engineering
* Supervised machine learning models
* Model comparison and evaluation
* Performance metrics analysis
* Kaggle workflow experimentation

## Dataset
The dataset contains patient health and clinical information used to predict the likelihood of heart disease.

Typical features include:
* age
* cholesterol levels
* blood pressure
* chest pain type
* resting ECG
* heart rate
* fasting blood sugar
* exercise-induced angina

The target variable represents the presence or absence of heart disease risk.

## Machine Learning Workflow
The project follows a structured ML pipeline:
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Feature selection and engineering
5. Model training
6. Model evaluation and comparison
7. Performance optimisation

## Models Explored
Examples of models explored include:
* Logistic Regression
* Random Forest
* Decision Trees
* Support Vector Machines
* K-Nearest Neighbours

Performance was evaluated using:
* accuracy
* precision
* recall
* F1-score
* confusion matrix analysis
